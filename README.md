# game-bot

MAX-бот АНО «Агентство развития игровой индустрии».

В одном боте собраны:

- приветственное меню Агентства;
- регистрация в сообщество;
- регистрация на игровую тусовку 18 сентября;
- заявки на стажировку;
- игра «Жизнь» от 16 до 60 лет, где один ход = один год и каждый год есть 4 варианта действий;
- итоговые очки, достижения и тип прожитой жизни;
- общий рейтинг игроков и рейтинг учебных заведений;
- простая административная статистика по команде `/stats`.

## Что уже есть в игре

Игрок начинает в 16 лет с деньгами, здоровьем, счастьем, навыками, репутацией, карьерой и отношениями. Внутри также считаются стресс, финансовая грамотность, социальный капитал, предпринимательский опыт, риск и зависимости.

Основная библиотека содержит **432 сценария**: 9 возрастных этапов × 12 тематических направлений × 4 варианта ситуаций. Сверху работают отдельные ключевые возрастные события, связанные сюжетные продолжения, карьерные линии и специализации, которые зависят от предыдущих решений игрока.

Темы библиотеки:

- образование и обучение в течение жизни;
- работа, собеседования, смена команды и лидерство;
- создание игр, геймджемы, плейтесты и релизы;
- дизайн, медиа, сценарии и другие креативные индустрии;
- мероприятия, игротеки, D&D и настольные ролевые клубы;
- личные финансы, кредиты, инвестиции и финансовая безопасность;
- здоровье, сон, стресс и профилактика;
- отношения, круг общения и совместные решения;
- цифровая безопасность, персональные данные и ответственное использование ИИ;
- предпринимательство, MVP, заказчики и работа команды;
- проекты для Уфы, волонтёрство, наставничество и развитие сообществ;
- отдых, хобби, поездки и баланс нагрузки.

Есть связанные сюжетные цепочки. Например: попробовать вейп → столкнуться с формированием привычки → решить, продолжать или отказаться; придумать игру → собрать команду → сделать вертикальный срез → выйти на питч → дойти до релиза; сделать MVP → получить первые реакции → проверить гипотезу или рискованно масштабироваться. Есть продолжения для карьерного роста, цифровых рисков, сомнительных финансовых решений, проектов в Уфе, наставничества, НРИ и собственного жилья.

Выборы имеют долгосрочные последствия. Сильная зависимость ежегодно влияет на здоровье, деньги и стресс, а хронически высокий стресс постепенно снижает здоровье и счастье. Игровая сессия хранит список уже увиденных событий, поэтому одна жизнь не должна повторять одно и то же событие.

Финальный результат ограничен 10 000 очками. Лучший завершённый результат игрока попадает в рейтинг.

## Карьера в Башкортостане

В 19 лет игрок выбирает широкую профессиональную среду, в 20 лет — конкретную профессию, а в 22 года — специализацию внутри выбранной профессии.

Доступны 10 профессиональных траекторий:

- 🎮 разработчик игр;
- 💻 IT;
- 🧪 нефтехимия;
- ⚙️ инженерия;
- 🩺 медицина;
- 📚 педагогика;
- 🎨 дизайн и медиа;
- 🚀 предпринимательство;
- 🌾 АПК и агротехнологии;
- 🏛 государственная и муниципальная служба.

Для каждой профессии есть четыре специальные карьерные события: вход в профессию, рост, лидерство и профессиональное наследие. Профессия влияет на игровые доходы и на то, какие ситуации появляются в ключевые годы.

### Специализации

У каждой из 10 профессий есть **4 специализации — всего 40 вариантов**. Специализация выбирается в 22 года и дальше меняет конкретную должностную лестницу, профессиональные события и игровой доход.

Примеры:

- разработка игр: `Геймдизайн / Программирование игр / Игровой арт и UI / Продюсирование игр`;
- IT: `Backend / Frontend / Data и AI / DevOps`;
- нефтехимия: `Технологические процессы / Лаборатория и данные / Автоматизация / Надёжность и безопасность`;
- инженерия: `Проектирование и CAD / Роботизация / Испытания и надёжность / Управление инженерными проектами`;
- медицина: `Клиническая практика / Диагностика / Профилактика / Управление медицинскими проектами`;
- педагогика: `Предметное преподавание / Игровые методики / EdTech / Методическая работа`;
- дизайн и медиа: `Графический дизайн / Видео / Медиа и SMM / Креативное продюсирование`;
- предпринимательство: `Продукт и стартапы / Продажи / Операционное управление / Социальное предпринимательство`;
- АПК: `Агрономия / AgroTech / Переработка / Агрологистика`;
- госслужба: `Аналитика / Цифровые сервисы / Молодёжные и общественные проекты / Проектное управление`.

Для каждой специализации есть собственная семиступенчатая лестница и три специальных сюжетных контрольных точки в 27, 38 и 49 лет. Это даёт **120 специализационных карьерных событий** поверх основной библиотеки и широких профессиональных линий.

Например, геймдев после выбора специализации перестаёт показывать общую должность `Middle-разработчик игр` и начинает использовать конкретные лестницы:

- геймдизайн: `Стажёр-геймдизайнер → Junior Game Designer → Middle Game Designer → Senior Game Designer → Lead Game Designer → Creative Director`;
- программирование: `Стажёр-разработчик игр → Junior Gameplay Programmer → Middle → Senior → Lead Programmer → Technical Director`;
- игровой арт: `Стажёр игрового арта → Junior Game Artist → Middle → Senior → Lead Artist → Art Director`;
- продюсирование: `Стажёр-продюсер → Junior Game Producer → Game Producer → Senior Producer → Lead Producer → Executive Producer`.

### Должности и повышения

Абстрактный показатель `career` преобразуется в конкретную должность. У каждой профессии и каждой специализации есть **7 карьерных ступеней** на уровнях 0, 1, 2, 4, 6, 8 и 10.

В карточке игрока показываются:

- профессия;
- специализация;
- текущая должность;
- карьерный уровень;
- следующая должность и сколько уровней осталось до неё;
- расчётный игровой доход за год.

Когда решение переводит игрока через карьерный порог, бот показывает отдельную строку `🎉 Повышение`. При выборе специализации широкая должность автоматически заменяется на специализационную.

Расчётный доход зависит от профессии, карьерного уровня, навыков и выбранной специализации. Например, внутри одного геймдева программирование, геймдизайн, арт и продюсирование имеют разные игровые коэффициенты дохода. Все цифры дохода используются **только для игрового баланса** и не являются статистикой рынка труда.

## Регистрации

Для сообщества и стажировки бот последовательно собирает:

1. ФИО;
2. номер телефона — можно отправить контактом MAX или написать вручную;
3. учебное заведение;
4. интересующие направления через multi-select кнопки.

Для тусовки собираются ФИО, телефон и учебное заведение.

Заявки сохраняются в PostgreSQL. Повторная отправка той же заявки обновляет существующую запись вместо создания дубля.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Укажите `BOT_TOKEN`.
3. При необходимости заполните `ADMIN_IDS`, `PARTY_PLACE` и `PRIVACY_URL`.
4. Запустите:

```bash
docker compose up -d --build
```

Логи:

```bash
docker compose logs -f bot
```

## Переменные окружения

```env
BOT_TOKEN=

PARTY_TIME=15:00
PARTY_PLACE=Место сообщим дополнительно

```

## Команды

- `/start` — главное меню;
- `/menu` — главное меню;
- `/game` — игра;
- `/top` — рейтинг;
- `/stats` — статистика для пользователей, перечисленных в `ADMIN_IDS`.

## Транспорт MAX

Сейчас MVP запускается через официальный пакет `@maxhub/max-bot-api` в режиме Long Polling. Для публичного production-развёртывания стоит переключить получение событий на Webhook с HTTPS и secret-проверкой.
